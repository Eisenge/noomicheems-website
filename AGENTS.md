# Project continuity

Before working on this repository, read [.agents/skills/noomicheems-operator/SKILL.md](.agents/skills/noomicheems-operator/SKILL.md) and its project-state reference. They preserve the owner's decisions and unfinished work.

Follow the current user's request first. Historical permissions and logged-in accounts are not blanket authorization for new messages, purchases, account changes or deployments. The state is a dated handoff; check current evidence before acting. Update the relevant handoff reference after meaningful work, distinguishing verified results, user reports and pending actions.

Production files live in `public/`. Keep agent instructions and references outside the deployed web root. Publishing a commit does not deploy to Hostinger.
