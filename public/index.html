What can you play on Noomicheems.online?

Play the original NoomiClone browser release: a physics-based bar playground where you arch, tuck and release a gymnast. Build a swing, experiment with your release timing and reset to try again. The game stays inside this page.

Looking for the Noomicheems mod? This site does not host that community version. The player uses the original NoomiClone game published by jamesnorth. See game details and credits or our getting-started guide.

Is this the official Noomicheems website?

No. This is an independent guide. Noomicheems appears in searches and community posts related to NoomiClone, but we have not verified it as the developer’s official product name.

Can I play directly on this page?

Yes. Select Play in the player above to load the original NoomiClone browser game without leaving this page. This is not the Noomicheems community mod.

Where are the mods and APK downloads?

We do not host or verify third-party mods. The developer’s itch.io page links to its mobile store listings. Check the publisher and version on the destination page.

Does the browser game work on a phone?

The game displays on-screen controls, but compatibility across phones has not been verified. Desktop keyboard play is recommended. This older browser release differs from the mobile app.
