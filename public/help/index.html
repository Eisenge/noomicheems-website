PLAYER HELP

Get back to the game

The player is still loading

The Unity browser build downloads game assets when started. Allow time on the first load. If the player stalls, use Reload game beneath it. Reloading restarts the game and loses the current attempt.

The keys move the page

Click inside the game first. Then use Left Arrow to arch, Space to tuck, Up Arrow to release and R to reset. Check the controls page for the complete list.

Fullscreen will not start

Use the Fullscreen button below the game or the platform’s button inside it. Browser support varies. You can still play in the normal page view.

Playing on a phone

The browser game shows on-screen controls, but we have not verified compatibility across phones. A desktop browser with a keyboard is recommended. Try landscape orientation for a larger player.

A map or mod is missing

This site uses the original NoomiClone browser release. The Noomicheems mod and newer mobile features are not included.
