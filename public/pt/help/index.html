Ajuda com NoomiClone

Resolva problemas de carregamento, teclado e tela cheia.

O jogo continua carregando

A versão Unity baixa arquivos ao iniciar. Aguarde no primeiro carregamento. Se não avançar, use Recarregar jogo; a tentativa atual será perdida.

As teclas movem a página

Clique dentro do jogo. Use ← para arquear, Espaço para agrupar, ↑ para soltar e R para reiniciar. Espere o carregamento terminar.

A tela cheia não abre

Experimente o botão do site ou o do player. O suporte depende do navegador. Ajustar à janela permite ver a cena completa sem tela cheia.

No celular

Tente a orientação horizontal. Não garantimos compatibilidade com todos os aparelhos; recomendamos computador com teclado.

Faltam mapas ou mods

Esta é a versão original para navegador. Mods e recursos mais recentes do aplicativo móvel não estão incluídos.
