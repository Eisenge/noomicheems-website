Bantuan NoomiClone

Atasi masalah pemuatan, keyboard, dan layar penuh.

Game masih memuat

Versi Unity mengunduh berkas saat dimulai. Tunggu pada pemuatan pertama. Jika berhenti, tekan Muat ulang game; percobaan saat ini akan hilang.

Tombol menggulir halaman

Klik di dalam game. Gunakan ← untuk melengkung, Spasi untuk menekuk, ↑ untuk melepas, dan R untuk mengulang. Tunggu pemuatan selesai.

Layar penuh tidak terbuka

Coba tombol di bawah game atau tombol pemutar. Dukungan berbeda menurut browser. Sesuaikan jendela dapat menampilkan seluruh adegan tanpa layar penuh.

Bermain di ponsel

Coba orientasi mendatar. Kami tidak menjamin kompatibilitas dengan semua perangkat; komputer dengan keyboard disarankan.

Peta atau mod tidak tersedia

Ini versi browser asli. Mod serta fitur terbaru aplikasi seluler tidak disertakan.
