Ayuda con NoomiClone

Soluciones para la carga, el teclado y la pantalla completa del juego.

El juego no termina de cargar

La versión Unity descarga archivos al iniciarse. Espera durante la primera carga. Si no avanza, pulsa Recargar juego; perderás el intento actual.

Las teclas desplazan la página

Haz clic dentro del juego. Usa ← para arquear, Espacio para agruparte, ↑ para soltar y R para reiniciar. La página debe haber terminado de cargar.

La pantalla completa no funciona

Prueba el botón del sitio o el del reproductor. El soporte depende del navegador. Ajustar a la ventana permite ver la escena completa sin activar la pantalla completa.

El juego en el teléfono

Prueba la orientación horizontal. No garantizamos compatibilidad con todos los teléfonos; se recomienda un navegador de escritorio con teclado.

Faltan mapas o mods

Esta es la versión original de navegador. Los mods y las funciones más recientes de la aplicación móvil no están incluidos.
