THE PHYSICS PLAYBOOK / CONTROLS

Know your next move.

The four controls below are published on the NoomiClone developer page. They apply to that browser release.

KeyActionPractice focus
Left arrowArchObserve the character’s position before adding another input.
SpacebarTuckCompare the tucked position with an extended position.
Up arrowLet goChange release timing one attempt at a time.
RResetRestart after an attempt.

If your keys do not respond

First open the homepage game and click inside its game area to focus it. Check that the page has finished loading. The published instructions do not document a map selector, re-grab key or touchscreen equivalents, so this guide does not invent those controls.

Practice with one change at a time

Try the same input sequence more than once before changing it. Then vary only the release timing. This is a practice suggestion, not a developer-confirmed high-score technique.
