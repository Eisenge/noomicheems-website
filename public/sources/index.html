GAME & DEVELOPER

The original NoomiClone browser game

Our homepage embeds the original browser release by jamesnorth using itch.io’s game-embed service. The game runs within our page.

Credits and source

The game, character, sound and gameplay belong to their respective creators. The source listing is NoomiClone by jamesnorth on itch.io. We do not claim to have created the game or to be its official publisher.

Which version is playable?

This is the original browser build, with arch, tuck, release and reset controls. It is not the Noomicheems community mod. Mobile videos can show maps and features that are absent from this older browser release.

How the player works

The game is hosted by itch.io and displayed through its documented game-embed service. The platform’s attribution and fullscreen controls remain visible. Availability depends on the developer and hosting platform.
